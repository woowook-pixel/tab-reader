# Fret 적용 기준

공통 기준은 `shared/DESIGN.md`, 토큰은 `shared/tokens.css`를 따른다. 이 문서는 Fret(구 타브 리더)에만 해당하는 내용이다.

## 앱 이름

- 표시 이름: "타브 리더" → `Fret`
- 상단 바 워드마크: `FRET`
- HTML `<title>`, manifest(있다면) `name`, `short_name`도 Fret로 변경

## 화면별 변경

### 악보 목록

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 가운데 제목 "악보" | 상단 바: 왼쪽 `FRET`, 오른쪽 텍스트 버튼 "+ 새 곡" (하단 연필 아이콘 기능을 이동) |
| 제목 | 없음(내비 제목만) | 44px 제목 "악보", 보조 라벨 "N개의 악보" (하단 바의 개수 표시를 이동) |
| 검색 | 회색 둥근 검색창 | 밑줄형 입력, placeholder "검색" |
| 곡 목록 | 색색의 음표 아이콘 + 곡명 + 꺾쇠 | 섹션 라벨 "곡" + 목록 행: 곡명, 오른쪽 "→". 음표 아이콘과 색 제거 |
| 저장 안내 | 회색 안내문 | 목록 아래 Gray 12px 안내문 유지 |
| 백업 및 복원 | 파랑·초록·회색 아이콘 행 3개 | 섹션 라벨 "백업 및 복원" + 목록 행 3개. 아이콘 제거, "텍스트로 백업·복원"은 오른쪽 "↓"(펼침) |
| 하단 바 | "6개의 악보" + 연필 아이콘 | 제거(개수는 보조 라벨, 새 곡은 상단 바로 이동) |

### 악보 보기

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 파란 "< 악보", 가운데 곡명, 파란 "편집" | 상단 바: 왼쪽 `FRET`, 오른쪽 텍스트 버튼 "← 악보", "편집" |
| 제목 | 내비 가운데 "A-ha - Take On Me" | " - " 앞부분을 보조 라벨(아티스트), 뒷부분을 40-44px 제목(곡명). " - "가 없으면 전체를 제목으로 |
| 섹션 이동 | 색 점 알약 칩(Intro, Riff, Verse 1, Chorus) | 밑줄 탭. 현재 보고 있는 섹션에 Ember 점 |
| 섹션 머리 | 색 사각 음표 아이콘 + 섹션명 | 섹션 라벨(대문자, 11px 800) |
| 코드만 있는 줄 | 파란 코드명 | 검정 18px 800 |
| 타브 블록 | 회색 둥근 박스 + 왼쪽 빨간 막대, 파란 코드명 | 박스 없음. 왼쪽 검정 2px 선 + 왼쪽 여백 12px. 타브와 코드는 `--pf-mono`, 코드명은 검정 700 |
| 반복 표시 | "x2" | 블록 오른쪽 검정 800 |
| 하단 조작 | 조절 아이콘, 원형 −/+, 파란 원형 재생 | 하단 고정 바: 텍스트 버튼 "보기 설정", "−" 숫자 "+"(아래 "스크롤 속도" 라벨), 검정 사각 "PLAY"(재생 중에는 "STOP") |

### 새 곡 (편집 시트)

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 파란 "취소", 가운데 "새 곡", 파란 "완료" | 상단 바: 왼쪽 `FRET`, 오른쪽 텍스트 버튼 "취소", "완료". 아래 44px 제목 "새 곡"(편집 시 "편집") |
| 제목 입력 | 흰 둥근 박스 | 섹션 라벨 "제목" + 밑줄형 입력 |
| 코드 찾기 | 주황·회색 아이콘 행 2개 | 섹션 라벨 "코드 찾기" + 목록 행 2개, 오른쪽 "↗"(새 탭) |
| 악보 텍스트 | 흰 둥근 큰 박스 | 섹션 라벨 "악보 텍스트" + 위 검정 1px, 아래 Line 1px 선 사이의 textarea, `--pf-mono` |
| 파일 불러오기 | 파란 아이콘 행 | 목록 행 "텍스트 파일(.txt)에서 불러오기" |
| 이미지 | (스크린샷 하단 잘림) | 같은 섹션 라벨 + 목록 행 방식. 이미지 미리보기는 흑백 처리하지 말고 원본 그대로(악보 이미지는 읽어야 하므로) |

## Ember 사용 위치 (Fret)

- 악보 보기의 현재 섹션 탭 표시 한 곳.

## 하지 말 것

- 타브 텍스트 파싱, 섹션 인식, 자동 스크롤 로직, 저장·백업 방식은 건드리지 않는다.
- 타브 블록의 글자 정렬이 깨지지 않게 고정폭 글꼴 외의 폰트를 타브에 쓰지 않는다.
- 섹션별 색 구분을 다른 색으로 대체하지 않는다(색 없이 이름으로만 구분).
